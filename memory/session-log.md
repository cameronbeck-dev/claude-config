## 2026-05-04 — personal-llm (C:\Users\GGPC\Documents\programming\personal-llm)
Fixed Sage's "no conversation history" bug. Three root causes: (1) the previous-conversation ID was lost when the user clicked "+ New" because setActive(null) cleared activeConversationId without preserving it; (2) summarization only triggered on the client-driven POST /conversations route, so page reloads or fresh sessions never produced summaries; (3) even when summaries existed, the LLM often wrapped its JSON output in markdown fences and JSON.parse threw silently, and SUMMARIES.json's timestamp field reflected summary-creation time rather than conversation activity time so Sage couldn't tell which conversation was actually most recent. Fixes: setActive(null) now preserves activeConversationId into previousConversationId; chatStream catches up unsummarized non-archived conversations on every fresh-conversation first message; new extractJson helper tolerates markdown fences and prose preamble (used in summarizeConversation, reviewMemory, trimAndMigrateSummaries); summarizeConversation made idempotent; lastMessageAt added to SummaryEntry and used to sort the system-prompt injection chronologically (formatted as a numbered list, most-recent first); failures log conversation id and 500-char LLM output preview. Wiped SUMMARIES.json so the catch-up rebuilds with the new format. Committed and pushed as cc99bd1.
